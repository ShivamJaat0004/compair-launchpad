# Compair Launchpad

Create a premium, modern, highly engaging, fully responsive corporate website for “COMPAIR PREMIUM WATER”, using the uploaded reference image as the primary visual, branding, product, colour and design reference.

The website should feel like a premium FMCG / packaged drinking water brand, combining trust, purity, modern distribution, strong business opportunity and premium hydration. Do not simply copy the reference poster. Use its visual language and brand identity to create a sophisticated, original website.

22. AUTHENTICITY RULE

Use the uploaded reference image as the master brand reference.

Do not redesign the Compair bottle into a completely different product.

Do not change the core pink/magenta identity.

Do not invent certifications, awards, statistics, manufacturing capacities, distributor counts, revenue figures or geographical claims unless supplied by the brand.

Where actual company information is unavailable, use editable placeholder content rather than making unsupported claims.

Where actual partner logos are unavailable, clearly use editable placeholder logos so they can later be replaced with genuine collaborations.
